# weather_dash_app
気象庁が公開する降水量データをDashで可視化するアプリケーション  
  
デモページ  
https://precipitation.lazyweb.mydns.jp/

ローカル起動  
- `data/mapbox_access_token.conf` にトークン記入
- アプリケーション起動
  ```
  $ docker compose up
  ```
